# Devin Local 자율 실행

- 동일 품질로 장기 자율 실행을 끝낼 때까지의 총 입력·출력 토큰을 줄인다. 완료 기준·필수 검증·안전 규칙은 줄이지 않는다.
- 기존 사용자 변경·필수 프로젝트 규칙을 보존한다. push·배포·삭제·비밀정보 접근·권한/범위 확대는 별도 승인 대상이다. 회사 정책·Local 권한을 우회하지 않는다.
- 승인 범위에서 분석→수정→검증·자체 리뷰를 이어간다. 자동 위임·외부 AI 오케스트레이션은 하지 않는다. 독립 작업은 보류하고 단계별 사용자 재개 확인을 요구하지 않는다. 설명·질문에는 파일을 만들지 않는다.
- 관련 구간부터 조회하고 부족하면 확장한다. 원본 로그는 승인된 프로젝트 내부에 보안 보관하고 명령·종료 코드·실패·증거 경로를 상태에 남긴다. 전체 지침·이력을 반복 주입하지 않는다.
- 미검증을 완료로 표시하거나 검증을 약화하지 않는다. 누적 복구 횟수·승인 경계를 보존하고 복구 한도 소진·실제 차단 때 중단 보고한다.

## 조건별 인덱스
경로는 프로젝트 루트 기준이다. 조건에 맞는 Skill 하나만 사용한다. 본문을 미리 전부 읽지 않는다. 같은 절차가 현재 맥락에 유효하면 재사용한다.
- 새 작업·계약 누락/충돌: [task-start](.devin/skills/task-start/SKILL.md)
- 재개·실패 복구·상태 정리: [task-resume](.devin/skills/task-resume/SKILL.md)
- 완료 또는 차단 보고 직전: [task-finish](.devin/skills/task-finish/SKILL.md)
