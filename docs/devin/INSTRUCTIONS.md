# Devin Local 절차 인덱스

상세 지침은 네이티브 Skills로 이동했다. 이 파일은 호환용 인덱스이며 시작마다 전체 지침을 읽는 진입점이 아니다.

| 조건 | 필요한 절차 |
|---|---|
| 새 구현·수정, 계약 누락·충돌 | [task-start](../../.devin/skills/task-start/SKILL.md) |
| 중단 후 재개, 실패 복구, 상태 정리 | [task-resume](../../.devin/skills/task-resume/SKILL.md) |
| 완료 또는 차단 보고 직전 | [task-finish](../../.devin/skills/task-finish/SKILL.md) |

조건에 맞는 절차만 사용한다. 설계·현재 상태·상세 증거는 해당 작업 파일에서 필요한 부분만 조회한다. 설치·지원 범위·비용 한계는 사람이 필요할 때 `.devin/README.md`를 확인한다.
